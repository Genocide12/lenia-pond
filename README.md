# Пруд Лении

Живая математика прямо в браузере, понятно в любом возрасте. Два мира:

- **Головастики** — канонический эксперимент Lenia: случайный шум (`первичный бульон`)
  самособирается в ~180 плывущих организмов. Они сталкиваются, сливаются, гибнут —
  и новые собираются из хаоса снова.
- **Грибы** — колониальный репликатор *Hydrogeminium limus*: одна клетка растёт,
  перетягивается и **делится** — и так до колонии из ~300 существ.

Реконструкция оригинальной [Lenia](https://github.com/Chakazul/Lenia)
Бёрта Ван-Чака Чана (Python/animals.json) на WebGL2.

**Живая версия:** GitHub Pages (ссылка в About репозитория)

## Управление

- **Пауза/Пуск** (или пробел), скорость ×1…×8, «Заново» (R)
- **Клик по пруду** — поселить жителя (головастика или гриб)
- У пруда нет краёв: уплыв за границу, существо появляется с противоположной стороны —
  счётчик жителей при этом не ошибается (периодическая связность)

## Дневник и честный подсчёт

Счётчик существ использует **периодический анализ связных компонент** (union-find
с объединением через края тора): существо, пересекающее границу, остаётся одним целым —
нет ложных «рождений» 1→2→4 на краю экрана. Трекер различает рождения, деления и гибель.

## Проверка корректности

- `bun run lint` — чисто
- `/selftest` — сверка WebGL-движка с эталонной NumPy-симуляцией вживую:
  - масса орбия и гриба совпадает с эталоном с точностью ~0,1 %;
  - деление клетки подтверждено в арифметике float32 (та же, что в GPU): первое деление
    ~1700 шагов, колония 270+ существ;
  - переход через край: население всегда 1, без скачков;
  - хаос самособирается в 120+ существ за 600 шагов.
- Эталоны воспроизводятся скриптами в `scripts/` (NumPy + scipy).
